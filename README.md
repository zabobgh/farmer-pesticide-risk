# แบบประเมินความเสี่ยงเกษตรกรจากการใช้สารเคมีกำจัดศัตรูพืช (นบก.1-56)
**อำเภอบ้านแพ้ว จังหวัดสมุทรสาคร**

เว็บแอปพลิเคชันสำหรับประเมินความเสี่ยงสุขภาพของเกษตรกรจากการสัมผัสสารเคมีกำจัดศัตรูพืช พร้อมระบบประเมินอาการ การตรวจระดับเอ็นไซม์คลอรีนเอสเตอเรส และการบันทึกข้อมูลเข้า Google Sheets อัตโนมัติ

---

## 🌟 จุดเด่นของระบบ
- **Offline First & Auto-Save:** กรอกข้อมูลต่อได้แม้อินเทอร์เน็ตหลุด ไม่สูญหาย พร้อมระบบเก็บคิวส่งอัตโนมัติเมื่อกลับมาออนไลน์
- **Thai Citizen ID Checksum & Masking:** จัดรูปแบบเลข 13 หลัก `X-XXXX-XXXXX-XX-X` อัตโนมัติ พร้อมตรวจความถูกต้องตามสูตร Modulo 11
- **Ergonomic Design:** ออกแบบตามเกณฑ์ Impeccable Design มี Contrast สูง อ่านง่ายแม้อยู่กลางแดด ปุ่มสัมผัสขนาดใหญ่เหมาะกับมือถือ/แท็บเล็ตภาคสนาม
- **Mobile Responsive:** รองรับหน้าจอมือถือ ตารางสารเคมีแปลงเป็น Card layout สวยงาม
- **Google Sheets Integration:** เชื่อมต่อตรงผ่าน Google Apps Script โดยไม่ต้องมีเซิร์ฟเวอร์ภายนอก

---

## 📊 วิธีเชื่อมต่อกับ Google Sheet

1. สร้าง Google Sheet ใหม่ (หรือเปิด Sheet เดิมที่ต้องการ)
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. คัดลอกโค้ดจากไฟล์ `google_apps_script.gs` ในหน้านี้ไปวางแทนที่โค้ดเดิม
4. กด **บันทึก (Save)**
5. กด **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ชนิด: **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ: **ตัวฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** *(สำคัญมาก!)*
6. คัดลอก **URL เว็บแอป (Web App URL)** ที่ได้
7. นำ URL มาแทนที่ในไฟล์ `index.html` ตรงบรรทัด:
   ```javascript
   const GAS_URL = 'https://script.google.com/macros/s/.../exec';
   ```
8. Commit และ Push ขึ้น GitHub ข้อมูลจะส่งเข้า Google Sheet ทันที!
